This is a project app for learning FastAPI and Qwik.

FastAPI is the backend running on python.  To activate the server on dev run the following

`uv run fastapi dev`

Qwik is the JS front end.  To activate the server run the following

`npm run dev`

This is assuming you already ran `npm install`

---

The goal of the app is to create a health tracker that tracks food intake, sleep, etc.
