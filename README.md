This is a project app for learning FastAPI and Qwik.

FastAPI is the backend running on python.  To activate the server on dev run the following

`uv run fastapi dev`

Qwik is the JS front end.  To activate the server run the following

`npm run dev`

This is assuming you already ran `npm install`

---

The goal of the app is to create a health tracker that tracks food intake, sleep, etc.

---

what does ikemen ni naru mean?

ikemen or イケメン is a Japanese slang term that means a handsome, cool, or attractive man

ni naru or になる is Japanese grammar that means to become" or "to turn into".  It describes a change from one state to another.

So this being a health app tracker for measuring diet, sleep, mood, etc... My thought pattern was that if you use the app, you will become a chill guy.
